# AtomLoom · 评审演示

AtomLoom 面向材料研究人员和学生，提供从电解质建模、分子动力学准备到轨迹分析的网页工作区。

**[打开在线演示](https://underbigbridge.github.io/AtomLoom/)** · [一页作品说明](WORK.md) · [正式网站](https://hkust-gz.fun/)

## 三分钟体验

1. 打开演示，展开算例输入，查看 320 帧合成轨迹的体系、原子选择及拟合条件。
2. 切换 Li–O RDF、Li–F RDF、配位分布、联合配位和输运图表。图表来自同一套轨迹的实际分析输出。
3. 下载样例输入和完整结果，也可单独下载曲线、自变量和因变量 CSV。
4. 想体验配方设计时，在[正式网站](https://hkust-gz.fun/electrolyte)载入 EC / EMC 示例，再带入 [GROMACS 模拟](https://hkust-gz.fun/md)工作台。

离线体验时，下载并解压[演示包](https://github.com/Underbigbridge/AtomLoom/releases/download/v1.0.1/AtomLoom_Demo_v1.zip)，双击 `demo/index.html`。在线与离线演示均使用常见浏览器，无需账号。正式网站的集群计算使用授权访问，合成算例用于说明流程和文件格式。

AI、第三方工具和样例数据来源见[声明](DECLARE.md)。
